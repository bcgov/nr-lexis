# LEXIS user manual: industry edition

This manual is for industry users of the Log Exemption Information System
(LEXIS): companies that apply to export unmanufactured timber from British
Columbia, companies that make offers on advertised timber, and agents acting
for them. You log in with a Business BCeID. The manual describes what you
see on screen and how to get a job done.

Ministry staff have their own edition.

## How to read this manual

- **Menu paths** are written as **Group › Menu item**, for example
  **Provincial › Application search**. The groups are in the left-hand menu.
- **On-screen labels** are in bold, exactly as LEXIS shows them.
- **You only see what your role allows.** If a menu item or button in this
  manual is missing for you, see [Who can do what](07-who-can-do-what.md).
- **You only see your own organization's records.** Everything you search,
  open and create belongs to the forest client you are working under, plus
  the Blanket Order in Council exemptions that are open to every applicant.
- **The screenshots use made-up sample data.** The names, numbers and volumes
  in them are not real applications.
