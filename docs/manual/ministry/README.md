# LEXIS user manuals: ministry roles

This manual is for ministry staff who use the Log Exemption Information
System (LEXIS), where applications to export unmanufactured timber are
reviewed, offers and decisions are recorded, exemptions are created and
approved, and permits are issued. You log in with IDIR. The manual covers
your role: what you see on screen and how to get a job done.

Each staff role has its own manual, and industry users have another.

## How to read this manual

- **Menu paths** are written as **Group › Menu item**, for example
  **Provincial › Exemption search**. The groups are in the left-hand menu.
- **On-screen labels** are in bold, exactly as LEXIS shows them.
- **You only see what your role allows.** If a menu item or button in this
  manual is missing for you, your role or regions don't grant it. See [Who
  can do what](09-who-can-do-what.md).
