# LEXIS user manual: ministry edition

This manual is for ministry staff who use the Log Exemption Information
System (LEXIS) to review applications to export unmanufactured timber,
record offers and decisions, create and approve exemptions, issue permits
and run reports. You log in with IDIR. The manual describes what you see on
screen and how to get a job done.

Industry users have their own edition.

## How to read this manual

- **Menu paths** are written as **Group › Menu item**, for example
  **Provincial › Application review**. The groups are in the left-hand menu.
- **On-screen labels** are in bold, exactly as LEXIS shows them.
- **You only see what your role allows.** If a menu item or button in this
  manual is missing for you, your role doesn't grant it. See [Who can do
  what](09-who-can-do-what.md).
- **Most roles are regional.** Read Only, Application Approver and Exemption
  Approver work with records in the Natural Resource Regions they were
  granted. Administrators work province-wide.
- **The screenshots come from a test system.** The people, companies and
  contact details in them are sample ones.
